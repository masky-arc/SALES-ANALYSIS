
# 🏬 Super Store Sales Analysis | Power BI Dashboard

## 📊 Project Overview

This project analyzes sales data from an E-commerce business named **Super Store** using **Microsoft Power BI**.  
The goal is to transform raw sales data into actionable insights through an interactive and visually rich dashboard.

This repository serves as:
- A **learning resource** for Power BI beginners
- A **portfolio project** for data analytics roles
- A **reference dashboard** for sales performance analysis

---

## 🎯 Objectives

- Analyze overall sales and profit trends  
- Identify high-performing categories and regions  
- Enable dynamic data exploration using slicers and filters  
- Forecast future sales based on historical data  

---

## ✨ Key Features

- Interactive Power BI dashboard  
- Sales forecasting  
- Drill-down and cross-filtering  
- User-controlled parameters  
- KPI-driven visual analysis  

---

## 🛠️ Tech Stack

- **Microsoft Power BI**
- **Power Query**
- **DAX (Data Analysis Expressions)**

---

## ⚙️ Getting Started

### Prerequisites
- Install **Microsoft Power BI Desktop**  
  👉 https://powerbi.microsoft.com/en-us/downloads/

### Steps
1. Clone or download this repository  
2. Open the `.pbix` file in Power BI Desktop  
3. Explore the dashboard using filters and slicers  

---

## 📈 Insights & Results

The dashboard provides insights into:
- Sales performance by category and region  
- Profit contribution across segments  
- Time-based sales trends  
- Forecasted future sales
